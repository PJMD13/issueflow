# IFCT092PO - Programación Web con Software Libre

## Clase 01

Introducción al desarrollo web y primera aplicación PHP.

## Ejecutar diagnóstico

```bash
php diagnostico.php
```

## Ejecutar aplicación

```bash
php -S localhost:8000 -t public
```

Abrir en el navegador:

`http://localhost:8000`

## Requisitos

- PHP 8.4 o superior
- Git
- Editor de código
- Navegador web
